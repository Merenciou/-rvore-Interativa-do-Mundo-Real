## API Utilizada

Este projeto consome a **Rick and Morty API** ([https://rickandmortyapi.com](https://rickandmortyapi.com)), uma API REST publica e gratuita que fornece dados sobre a serie animada Rick and Morty.

Endpoints utilizados:

- `GET /api/location` - Retorna uma lista de localizacoes do universo da serie
- `GET /api/character/{id}` - Retorna dados de um personagem especifico


A API e apenas para leitura, entao todas as operacoes de insercao e exclusao sao feitas localmente no estado da aplicacao.
